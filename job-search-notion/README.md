# Job Search HQ (Notion template): hosted images

Public image hosting for the Job Search HQ launch.

- `pins/`: 24 Pinterest pins (1000x1500). `pins.csv` in the launch bundle points at `main/job-search-notion/pins/<name>.png`, so this folder must be on `main` before the first scheduled pin (13 Nov 2026, 14:15 UTC).
- `store/`: Gumroad cover images (1280x720) and the square thumbnail (1000x1000).

The images are generated by the build script in the project bundle (`job-search-notion/source/build.sh`), not edited by hand.
